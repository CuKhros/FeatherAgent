# FeatherAgent v1.2.1-rc.4.5 — 变更说明

公开仓库候选版，2026-11-26。本版修复 rc.4.4 Windows 复测的 N29–N31，尚未替代稳定版。

## N29 — 写文件任务跳过硬判据门禁

rc.4.4 复测中，下面这条任务仍然得到 `review.finished status=degraded rounds=0`：

> 请用工具把三条关于「内存管理」的要点写入 workspace/notes3.txt，每条一行，以「- 」开头

文件实际已写入，但 guide 两次被拒：第一次是整份清单没有硬判据，第二次是 `must_include:["-"]` 只有 1 个字，触发“术语至少 2 字”。三条规则互相冲突：必须有硬判据、术语至少 2 字、文件任务交 judge。

修法：解析结果 `file_task: true` 时，`parse_rubric_with_input` 只保留 `id/criterion/check/weight/judge_only/file_task`，剥掉 `must_include`、`must_not_include`、`min_points`、`pattern`、`regex`、`hard`、`match`、`min_matches`，把条目加入 `judge_only` 后直接继续。guide 提示对写文件任务只要求 `criterion/check`，不写硬键、不猜文件正文。`review_prepare` 不再因“零硬判据”逼写文件任务重试。

测试：`review_rubric_file_task_bypasses_symbol_term_limit`；`REVIEW_WRITE` 集成夹具改为 N29 的坏符号判据（`must_include:["-"]`、`min_points:3`、`pattern:"(?m)^- "`），仍要求 `approved` 且 judge `votes>0`。

## N30 — Windows 写入门禁在边缘标 advisory

rc.4.4 报告里 `write_p95_lt_10ms` 偶发变红，但 `reliability` 仍是 `high`，bench 本身能完整结束。单次边缘抖动不应把整轮判红。

修法：`bench` 计算 `write_p95`、`write_raw` 与 `write_margin`。Windows 上 P95 在 10–20 ms 之间标 `advisory`；超过 20 ms 才 `fail`。低可信度主机在 4 倍阈值内也标 `advisory`。平台写 key 使用 effective 结果，`gates` 新增 `write_gate_status`（`pass|advisory|fail`）与 `write_gate_raw`。Linux 仍按 100 µs 判定。

测试：`write_gate_marks_windows_edge_jitter_as_advisory`；CI 现在会拒绝缺失或非法的 `write_gate_status` / `write_gate_raw`。

## N31 — L17 识别粗体编号

large-1 的 L17 被判 1.5/3，因为列表正则只认 `1.`、`-`、`*`，不认 `**1.**`；答案实际有三条。

修法：`docs/model-test-reports/exam-papers/large-1.json` 的列表判据同时识别 `**1.**`。这是测试评分规则，不是产品改动；rc.4.4 的历史分数按当时规则保留。
