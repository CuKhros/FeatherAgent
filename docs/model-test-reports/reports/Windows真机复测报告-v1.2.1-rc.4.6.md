## 4. N32 ～ N35 验证

### 4.1 N32：Windows 路径 / 长 JSON ✅（核心已修）

写文件任务连跑 3 次（review 开启）：

| # | 结果 | 说明 |
|---|---|---|
| 1 | `degraded` | `审批项 c3 的 evidence 过短（少于 10 字）："三条要点已写入文件"` |
| 2 | `unapproved` | 判据未满足 |
| 3 | **`ok` / approved** | `verdict pass=True, votes=1` |

**rc.4.5 的 `invalid escape at line N column 43` 彻底消失** —— 路径转义修复生效，`votes=1` 说明 judge 正常参与。

**但引出一个新问题（N36）**：evidence 长度门限（≥10 字）会误伤短句中文。
`"三条要点已写入文件"` 只有 9 个字，被判不合格 → 重试 2 次仍不合格 → degraded。

`"三条要点已写入文件"` 长度：9 字（中文按字符计）——**门限 10 字对中文太严**，建议按"字符数 ≥10 或词数 ≥5"或降到 6。

### 4.2 N33：输出上限 ✅

| 题 | rc.4.5 长度 | **rc.4.6 长度** | `truncated` | 倍数 |
|---|---|---|---|---|
| M15（HTTPS 握手） | 136 字 | **1463 字** | False | **10.8×** |
| M20（可观测性三件套） | 390 字 | **3508 字** | False | **9.0×** |

**证实 rc.4.5 的截断源自 512 输出上限**，放开到 2048 后答案完整。
`truncated=False` 也提供了区分"模型自己停"与"被判据截断"的手段。

### 4.3 N34：bench 契约 ✅

```
第1次 gates: 8 项, 全布尔=True
      失败=无
```

`gates` 只剩布尔判定，`*_raw` / `*_status` / 阈值 / `reliability` 全部收进 `diagnostics` —— **契约清晰**。

### 4.4 N35：CPU 采样 ✅

| # | `env.cpu_load_pct` | `mem_load_pct` | `reliability` |

| 1 | **25** | 81% | medium |

### 6.1 关键观察 1：FA 会主动调工具算数学

ML10（∫₀¹ x²√(1−x²) dx，需要三角代换）上：

```
FA: tool_call tool.shell {"cmd":"python3 -c \"import sympy; print(sympy.integrate('x**2*sqrt(1-x**2)', ...))"}
```

**模型试图用 shell 调 sympy 求积分**，但本次启动只放行了 `tool.fs.write,tool.fs.read`，shell 被拒 → 最终 0 分。

**结论**：数学/计算类任务若不加 `tool.shell` 权限，**FA 的"用工具算"策略会反被权限挡住**。
建议：跑数学卷时 `--allow` 加上 `tool.shell`，或明确在提示词里禁止调用工具。

### 6.2 关键观察 2：FA 仍有「只写标题就停」的短答案

| 题 | FA 长度 | 结果 |
|---|---|---|
| MS2 | **37 字** | 只输出标题，丢 2 分 |
| ML02 | **109 字** | 输出答案一句话就停，丢 2 分 |
| ML10 | 116 字 | 工具调用文本，0 分 |

N33 把上限从 512 提到 2048，**但这几例不是被截断**（`truncated` 未标记），而是**模型自身提前 stop**。
建议：对"要求完整推导"的题目，在提示词里显式要求"必须写完推导过程"，或用 `finish=length` 之外再检测"答案过短"。

### 6.3 关键观察 3：FA 的强项集中在「结构化证明 / 线代步骤」

| 类型 | 裸跑 | FA | 差值 |
|---|---|---|---|

## 9. 复现命令

```powershell
cd FeatherAgent-1.2.1-rc.4.6-windows-x64
.\featheragent.exe serve --root . --provider provider-ollama --model qwen3.5:4b

# N34 / N35
.\featheragent.exe bench --root . --json | ConvertFrom-Json |
  Select-Object -ExpandProperty diagnostics | Select platform, write_gate_status, write_gate_raw
.\featheragent.exe bench --root . --json | ConvertFrom-Json |
  Select-Object -ExpandProperty metrics | Select-Object -ExpandProperty env

# 数学卷（断点续跑；如需工具辅助请加 --allow tool.shell）
cd ..\exam_papers
python exam_run.py math-small 8 <FeatherAgent 目录>
python exam_run.py math-large 5 <FeatherAgent 目录>
```
