## 4. N36：中文 evidence 门限 ⚠️ 未取得有效读数

两次尝试均返回：

```
model.message {"finish":"interrupted", ...}
chat.finished {"status":"stopped", "review":{"degraded":true, "rounds":0}}
```

第 3 次直接 `exit=1`。**进程在 review guide 阶段被中断，没能走到 verdict**。

推断原因：前一次用 240s 超时把 chat 客户端强杀，内核侧留下未清理的 turn，后续会话被判定为 `interrupted`。
**属测试环境状态问题，不是被测代码的结论**，因此本轮**不对 N36 下判定**。

（changelog 描述的新门限为「≥6 个 CJK 字符 / 3 个英文单词 / 10 个 ASCII 字母数字」，
`三条要点已写入文件` 的 9 个 CJK 字符按该规则应被接受——但这一点需要在干净环境下复核。）

## 5. N39：公式变体 ⚠️ 部分

ML02 的判据要求同时命中 `π²/6`、`巴塞尔`、`收敛`。本轮 FA 输出 1568 字（比 rc.4.6 的 109 字完整得多），
但只命中 1/3 → 1.0 分。

**可能原因**：模型的公式写法仍是 LaTeX 变体（如 `\dfrac{\pi^2}{6}`、`\zeta(2)`），
而判据只覆盖 `π²/6` / `pi^2/6` / `\frac{\pi^2}{6}` 三种。

**建议**：判据再加 `\dfrac`、`\zeta(2)`、`π²/6`（上标 2 为 Unicode）、`(π^2)/6` 等写法；
或干脆对"数值/公式类"判据采用**数值等价**判断（解析表达式后比较），而不是字符串匹配。
