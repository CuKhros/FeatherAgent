# FeatherAgent 测试试卷库

用于对比「小模型直接裸跑」与「同一模型在 FeatherAgent 环境中运行」的答卷差异。本目录只收录试卷 JSON，不包含运行器、代理配置或历史结果；可用任意兼容的跑卷脚本读取。

## 试卷

| 文件 | 规模 | 题数 | 满分 | 覆盖 | 建议用途 |
|---|---|---|---|---|---|
| `small-a.json` | 小 | 8 | 20 | 代码 / 调试 / 翻译 / 知识 / 数学 / 摘要 / 设计 / 推理 | 常规回归，约 8 分钟双跑 |
| `small-b.json` | 小 | 8 | 22 | SQL / 正则 / 日志 / 并发 / 测试 / 重构 / 缓存 / 接口 | 工程向常规回归，约 10 分钟双跑 |
| `small-c.json` | 小 | 6 | 15 | 翻译 / 改写 / 术语 / 纠错 / 压缩 / 问答 | 语言类快速回归，约 6 分钟双跑 |
| `large-1.json` | 大 | 20 | 54 | 八个领域的完整版 | 完整回归，约 25 分钟双跑 |
| `large-2.json` | 大 | 20 | 60 | 分布式 / 数据库 / 性能 / 安全 / 测试 / 运维 / 协议 | 工程深水完整回归，约 30 分钟双跑 |

每份试卷的 `full_score` 等于 `questions[].full` 之和；报告引用时请注明试卷 ID。

## 格式

```json
{
  "id": "small-a",
  "name": "小试卷 A · 通用八题",
  "size": "small",
  "full_score": 20,
  "desc": "覆盖说明",
  "questions": [
    {
      "id": "A1",
      "domain": "代码",
      "prompt": "题目正文",
      "full": 3,
      "checks": [
        {"name": "函数定义", "type": "regex", "val": "def ", "w": 1}
      ]
    }
  ]
}
```

`checks[].type` 目前使用两类规则：

- `regex`：答案中必须匹配 `val`；`w` 为最少出现次数，例如“三条列表”可设 `w: 3`。
- `len_le`：答案长度必须大于 0 且不超过 `val`。

空答案按 0 分处理。部分题目用多条 `checks` 拆分要点，单题得分按通过项比例计算，最高不超过 `full`。

## 打分局限

规则化打分只反映**覆盖面**，不反映**正确性**：

- 代码题未实际执行，未做编译/运行校验；
- 翻译未做回译比对；
- 设计、推理、摘要等主观题只查关键词与结构。

因此结论应看**同一模型在两种环境下的相对差异**，不要把绝对分当成质量结论。

## 版本说明

`large-1.json` 的 L17 列表判据同时识别 `1.`、`-`、`*` 和 `**1.**` 四种行首形式，避免粗体编号被误判为 0；历史报告中的 rc.4.4 分数按当时的旧规则记录，未回溯重算。
